# React Redux Playlist App

View Project: [https://react-redux-media-playlist.netlify.app/](https://react-redux-media-playlist.netlify.app/)

## Description

An application coded in React and Redux with Redux Toolkit that enables the user to create media playlists comprised of randomly generated songs or movies. Add items, delete items, or reset both playlists at once.
